# 命令索引

> 本文件由 `npm run gen:commands` 从 `src/app/commandTable.ts` 生成，**不要手改**；
> 与命令表是否同步由 `npm run audit:discoverability` 的 C8 判据把关。
>
> 每条命令写明「解决什么问题 / 结果去哪 / 会不会写盘」。命令面板（`Ctrl+Shift+P`）
> 支持按标题、说明和可搜词匹配，输入用途（如「发给别人」）也能命中。

共 134 条命令，按菜单分组。

## 文件

### file.open · 打开文件…

从磁盘打开一个文件，按扩展名自动选语法高亮

- 结果去向：不写盘 —— 打开的文件进入新标签；已打开的同路径文件会复用标签
- 入口：菜单「文件」

### file.quickOpen · 快速打开文件…

按文件名快速跳到工作区里的文件

- 结果去向：在面板里显示 —— 输入文件名片段即可过滤；↑↓ 选择、Enter 打开
- 可搜词：快速打开、找文件、ctrl+p、跳转文件
- 入口：菜单「文件」

### file.new · 新建未命名文档

新建一个空白的未命名文档，保存时再选路径

- 结果去向：不写盘 —— 未保存前不落盘；首次保存时让你选路径
- 可搜词：新建、新文件、untitled
- 入口：菜单「文件」

### file.save · 保存

把当前标签的改动写回原文件，不弹路径选择

- 结果去向：不写盘 —— 写回原路径并保持原编码；未命名文档会先让你选保存位置
- 可搜词：ctrl+s、存盘、保存文件、写回磁盘
- 入口：菜单「文件」

### file.saveAs · 另存为…

把当前内容另存为新文件，原文件保持不变

- 结果去向：生成文件 —— 新路径由你选择，原文件不动；保存后编辑的是新文件
- 可搜词：另存、换个名字、复制一份、save as
- 入口：菜单「文件」

### file.saveAll · 全部保存

一次保存所有有未保存改动的标签

- 结果去向：不写盘 —— 只写有改动的标签；失败时逐条列出是哪个文件
- 可搜词：全部保存、批量存盘、一次存完
- 入口：菜单「文件」

### file.saveAsEncoding · 另存为指定编码…

用指定编码另存当前文件，可顺带转码（如 GBK 转 UTF-8）

- 结果去向：生成文件 —— 写入新文件还是覆盖原文件由你选；确认前可先看预览
- 可搜词：转编码、gbk 转 utf-8、另存编码、乱码修复
- 入口：菜单「文件」

### file.reload · 重新载入当前文件（丢弃未保存修改）

从磁盘重新读取当前文件，丢弃未保存的改动

- 结果去向：不写盘 —— 会丢失未保存修改，执行前有确认
- 可搜词：重新载入、丢弃改动、还原、重新打开
- 入口：菜单「文件」

### file.reopenClosed · 重新打开关闭的标签

重新打开最近关闭的标签，恢复光标与滚动位置

- 结果去向：不写盘 —— 按关闭顺序逐个恢复；文件已删除时会提示不存在
- 可搜词：恢复标签、撤销关闭、重开、ctrl+shift+t
- 入口：菜单「文件」

### file.closeTab · 关闭当前标签

关闭当前标签，有未保存改动时先询问

- 结果去向：不写盘 —— 未保存时会问保存 / 不保存 / 取消
- 可搜词：关闭标签、关掉、ctrl+w
- 入口：菜单「文件」

### file.quit · 退出

退出应用，逐个处理未保存的标签

- 结果去向：不写盘 —— 有未保存改动时逐个确认；会话与草稿会先落盘
- 可搜词：退出、关闭应用、结束
- 入口：菜单「文件」

### file.recent · 最近打开的文件…

从最近打开的文件里选一个重新打开

- 结果去向：在面板里显示 —— 列表来自本机记录；文件已移动时会提示找不到
- 可搜词：最近文件、history、上次打开的
- 入口：菜单「文件」

### fetch.open · 从网址抓取网页…

输入网址抓取网页正文，转成 Markdown 存到本地

- 结果去向：生成文件 —— 产物是 .md 文件，目录在对话框里选；抓取失败会给出原因
- 可搜词：抓网页、网页转 markdown、保存文章、离线阅读
- 入口：菜单「文件」

### file.exportMarkdown · 导出 Markdown（当前 HTML 文件）

把当前 HTML 页面转成 Markdown 文件，保存在原文件旁边

- 结果去向：生成文件 —— 产物是同目录同名的 .md 文件，不修改原 HTML
- 可搜词：转成 md、html 转 markdown、导出 md、给文档留个底
- 入口：菜单「文件」

## 比较

### diff.unsaved · 比较：与磁盘内容（未保存改动）

对比当前标签与磁盘内容，看还没保存的改动

- 结果去向：在面板里显示 —— 只读对比；可直接导出 .patch 发给别人
- 可搜词：未保存对比、和磁盘比、看改了啥、diff、未保存补丁、把改动存成 patch
- 入口：菜单「文件」

### diff.pickFile · 比较：与文件…

把当前文件与磁盘上另一个文件逐行对比，结果只读，可导出 .patch

- 结果去向：在面板里显示 —— 左侧是当前文件、右侧是所选文件；不改任何文件
- 可搜词：比两个文件、文件对比、diff、patch、找不同、两个文件差异、对比结果留底
- 入口：菜单「文件」

### diff.compare · 灵活比较…

两侧任选来源（当前标签 / 当前选区 / 磁盘版本 / 已打开的文件 / 磁盘文件 / 剪贴板 / 空文本），内容可编辑后比较

- 结果去向：在面板里显示 —— 两侧文本框可直接修改，停顿后自动重算；结果是只读对齐视图，可复制补丁
- 可搜词：任意内容比较、剪贴板对比、文本对比、对比两段、改完再比、diff
- 入口：菜单「文件」

## Git

### git.pull · 拉取（快进合并）

从远程拉取当前分支并快进合并，不改写本地提交历史

- 结果去向：改动 Git 仓库 —— 只做快进合并；分支已分叉时提示先处理，不会强推或重置
- 可搜词：git pull、拉取、同步远程、更新代码
- 入口：菜单「Git」

### git.push · 推送

把当前分支的本地提交推送到远程同名分支

- 结果去向：改动 Git 仓库 —— 推送的是已提交内容；未提交的改动不受影响
- 可搜词：git push、推送、上传代码、同步到远程
- 入口：菜单「Git」

### git.pickBranch · 切换分支…

列出本地分支并切换，切走前会先确认未保存的改动

- 结果去向：在面板里显示 —— ↑↓ 选择、Enter 切换；未保存的改动会提示先保存
- 可搜词：切换分支、git checkout、git switch、换分支
- 入口：菜单「Git」

### git.showHistory · Git：查看提交历史

按时间查看当前工作区的提交记录，选中一条可看它改了哪些文件

- 结果去向：改动 Git 仓库 —— 选中提交后右侧显示它与上一版的差异，可复制或导出 .patch
- 可搜词：git log、查看改动记录、看看谁改的、提交历史
- 入口：菜单「Git」 · Git 菜单 · 源代码管理侧栏

### diff.gitHead · 比较：与 Git HEAD

把当前文件与 Git 里最后一次提交的版本对比，可导出 .patch

- 结果去向：改动 Git 仓库 —— 对比结果只读，不修改文件；导出得到统一 diff 补丁，可用 git apply 应用
- 可搜词：git diff、和上次提交比、看改了哪、patch、git apply、发给别人、留个底
- 入口：菜单「Git」

### diff.gitIndex · 比较：与 Git 暂存区

把当前文件已暂存的内容与最后一次提交对比，看即将提交什么

- 结果去向：改动 Git 仓库 —— 对比对象是暂存区；不会改动暂存内容或工作区文件
- 可搜词：git diff --cached、暂存区对比、看暂存了什么、HEAD、暂存区补丁、即将提交的 diff
- 入口：菜单「Git」

### git.blameDialog · Git：打开当前文件的 Blame 列表

列出当前文件每一行的最后修改人与提交，定位问题引入点

- 结果去向：在面板里显示 —— 列表按行号排列；点击可跳到该行，不修改文件
- 可搜词：blame、谁改的、最后一笔、追查改动
- 入口：菜单「Git」

### git.inlineBlame · 切换行内 Git Blame（跟随光标）

### git.toggleReadOnly · Git 只读模式（查看 / 可写切换）

切换 Git 只读模式：只查看改动，避免误改正在用的仓库
