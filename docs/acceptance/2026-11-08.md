| 三轮 N5 | 过滤块复用同一 4MB 缓冲，`drain` 回收前缀 | `large.rs`（`append_block`） | 跨块半行 / 无换行块 2 条单测 |
| 0.8.1 附加 | 帮助对话框宽度与主题适配；标签整块可点击激活 | 提交 `8f583a4` | 手工观感 |

未修项与理由：

- **P1-1 停手全量指纹 / P1-2 整篇撤销栈 / P1-3 草稿副本**：都会改变脏点时机、可撤销性或崩溃兜底，需单独立项并配 UI 验收。
- **§4-2 重载重扫大文件**：重载语义是「干净重放会话」，复用旧索引与 P0 的释放目标冲突；重载属低频手动操作。
- **PathGuard 无 `remove_path`**：授权是进程级已知路径，同一文件可能在别的标签仍打开，按标签撤销会导致保存被拒。
