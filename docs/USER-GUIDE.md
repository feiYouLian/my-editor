# 使用手册

面向使用者的操作说明。功能清单见 `README.md`；设计细节见根目录技术设计文档；遇到具体问题见 [`FAQ.md`](./FAQ.md)。

## 1 这是什么，适合谁

一个 Windows 优先的桌面文本编辑器：安装包约 3 MB，双击即开，内置文件树、工作区搜索、Git、终端、差异比较、大文件只读视图和一批文本工具。

**适合**：看日志、改配置、写 Markdown 笔记、临时跑脚本、试接口、对比两个文件、在内网离线机器上用。
**不适合**：中大型工程的日常开发（没有代码补全、跳转定义、类型检查、重构），需要断点调试的场景。

## 2 五分钟上手

| 想做的事 | 操作 |
| --- | --- |
| 打开文件 | `Ctrl+O`，或把文件拖进窗口 |
| 打开一个项目目录 | 首屏「打开目录」，之后文件树出现在左侧 |
| 不记得功能在哪 | `Ctrl+Shift+P` 打开命令面板，输入关键词（**所有功能都在这里**） |
| 按文件名跳转 | `Ctrl+P` |
| 改设置 | `Ctrl+,` |
| 看当前所有快捷键 | 首屏「快捷键速查」，或菜单「设置 → 快捷键速查…」 |
| 切换终端 | ``Ctrl+` `` |
| 打开/关闭侧栏 | `Ctrl+B` |

打开过的文件、光标位置、侧栏宽度会在下次启动时自动恢复。

## 3 界面导览

```
┌─ 标题栏：菜单（文件/编辑/选择/转到/视图/比较/工具/设置）· 运行按钮 · 窗口控制 ─┐
├─ 侧栏（Ctrl+B）──┬─ 标签栏 ──────────────────────────────────┤
│  正在打开的文件   │  面包屑（可点目录层级下钻）                 │
│  文件 / 搜索 /    │                                            │
│  大纲 / 源代码管理│  编辑区（或预览 / 差异 / 大文件视图）        │
│                  ├─ 底部面板：查找结果 / 运行输出 / 终端 ──────┤
├──────────────────┴────────────────────────────────────────────┤
│ 状态栏：路径 大小 编码 换行 语言 缩进 光标 行数 脏标记 空白 …  ⚠ 消息 │
└───────────────────────────────────────────────────────────────┘
```

**状态栏是可点的**，这是最容易被忽略的高频入口：

- 点**编码**：切换 / 重新解释为其它编码
- 点**换行符**：在 LF / CRLF / CR 间切换（只改内存，保存时落盘）
- 点**语言**：手动指定高亮语言（自动识别不准时用）
- 点**空白字符**：显示 / 隐藏空格与制表符
- 点**分支名**：切换 Git 分支；旁边的同步图标 = 拉取 + 推送
- 点 `⚠ N`：打开通知中心（待处理提示 + 最近消息）
- 点**消息文字**：直接打开「最近消息」

状态栏显示哪些字段、顺序如何，都能在「设置 → 编辑器与布局」里调整。

## 4 常见工作流

### 4.1 看一个大日志（几十 MB 到几 GB）

直接打开 `.log` 文件或 ≥ 20 MB 的文件即可。它会进入**只读虚拟视图**：

- 不会把整个文件读进内存，滚动时按需读取
- 顶部有过滤框（支持正则），命中结果分批到达
- 右侧 Minimap 标出命中位置
- 需要真正编辑时用视图里的「以编辑器打开」逃生门（大文件可能失败，会明确警告）

### 4.2 改配置文件，不破坏编码和换行

1. 打开文件，看状态栏的**编码**和**换行符**是否是期望值（GBK 文件会自动识别，识别错时状态栏编码处有 `⚠`）
2. 改完 `Ctrl+S`
3. 保存是原子的（临时文件 + fsync + 重命名），原 BOM 与换行符会保留

需要转码另存时用「另存为指定编码…」，原文件不受影响。

### 4.3 写 Markdown 并导出

- 右上角切「编辑 / 预览 / 双栏」；双栏比例可拖动，滚动联动
- 纯预览模式下 `Ctrl+F` 在渲染结果里查找
- 右键菜单有加粗 / 斜体 / 高亮 / 插入表格
- 导出：右键 → 导出 HTML / Word / PDF（本地图片会内联，移到别的机器也能看）

### 4.4 临时跑一段脚本

按 `F5` 运行当前文件（Python / Node / Java），或直接写一段 `curl` 命令按 `F5` 执行（**不用保存**，有选区时只跑选区）。

- 输出在底部面板，错误堆栈会分色、位置可点击跳转
- 30 秒超时、输出上限 1 MB
- 需要交互式输入时用 `Ctrl+F5`：把命令送进内置终端

### 4.5 Git 日常

侧栏「源代码管理」：分支与 ahead/behind、文件级与**行级**暂存、提交、放弃更改。

**放弃更改仍不可撤销**，但覆盖 / 删除前会把工作区内容快照到配置目录 `discard-backup/<时间戳>/`（保留最近 10 次）。要找回就手动从那里复制回来——应用内没有一键还原。

- 点文件看 HEAD ↔ 工作区的差异；也支持与暂存区比较
- 命令失败会弹出完整输出（可复制），并同时记进通知中心
- 拉取/推送用状态栏的同步图标

> **私有仓库推送失败**：本应用不代管 Git 凭据。先在系统终端里 `git push` 完成一次认证（凭据助手会记住），再回来推送。

### 4.6 对比两个文件 / 与磁盘比较

「比较」菜单：与磁盘内容、与指定文件、与 Git HEAD、与 Git 暂存区。差异视图支持块级「采用左侧 / 采用右侧」，可导出补丁。

> 单侧文本超过 4 MB 会拒绝比较并说明原因（避免把两个大文件读进内存）。

### 4.7 批量替换并后悔

侧栏「搜索」视图（`Ctrl+Shift+F`）：输入 → 预览每个文件的命中 → 批量替换。

替换前会把原文快照存到应用配置目录，替换后可点「撤销上次替换」。**只能撤销最近一次，且重启后失效**——涉及重要文件时建议先提交 Git。

### 4.8 列块编辑

`Alt` 拖选出一块矩形区域，按 `Alt+C` 打开列编辑器：插入固定文本、递增序号（可补零）、日期等。

## 5 设置

三种进入方式，改的是同一份 `config.json`：

1. `Ctrl+,` 打开设置中心（外观主题 / 编辑器与布局 / 文件与会话 / 快捷键 四页）
2. `Ctrl+Shift+P` 搜到具体设置项
3. 直接编辑 `config.json`，然后在设置页点「重新加载配置」（热生效，不用重启）

**快捷键**：设置 → 快捷键页可录制重绑、检测冲突、恢复默认。标为「固定」的键位（撤销、删行、移动行、折叠、书签等）不可改绑。
新增能力只用空闲键，不会改动已有键位的功能（例如 `Ctrl+D` 始终是删行）。

### 5.1 自定义编辑器主题

内置三套语法主题（深色 one-dark / 浅色 / 高对比度）之外，可以放自己的配色文件：

1. 设置 → 外观主题 → 点「打开主题目录」。首次会在配置目录生成 `themes/example-slate.json` 示例。
2. 复制成新文件（文件名即主题名，只允许字母、数字、`-` `_` `.`），改配色。
3. 回到设置页点「重新读取主题」，在下拉框里选中它 —— 立即生效，不用重启。
4. 直接改已有文件也可以，同样点「重新读取主题」。

文件格式（`ui` 可整段省略，省略时结构色由 `dark` 决定；`syntax` 至少要给一项）：

```json
{
  "dark": true,
  "ui": {
    "background": "#0f172a",
    "foreground": "#cbd5e1",
    "caret": "#e2e8f0",
    "selection": "#1e3a5f",
    "activeLine": "#152033",
    "gutterBackground": "#0b1220",
    "gutterForeground": "#64748b"
  },
  "syntax": {
    "keyword": "#c792ea",
    "string": "#c3e88d",
    "number": "#f78c6c",
    "comment": "#64748b",
    "variableName": "#cbd5e1",
    "function": "#82aaff",
    "typeName": "#ffcb6b",
    "propertyName": "#89ddff",
    "operator": "#89ddff",
    "bracket": "#f07178",
    "tagName": "#f07178",
    "attributeName": "#f78c6c",
    "heading": "#82aaff",
    "link": "#82aaff",
    "invalid": "#ff5370"
  }
}
```

- `syntax` 可用键就是上面 15 个；写错键名不会生效，设置页会提示「忽略了不认识的键 xxx」。
- 颜色写 CSS 颜色值（`#rrggbb` / `rgb()` / 命名色）；含 `;` `{` `}` `@` 或 `url(` 的值会被拒绝，避免破坏样式。
- `dark` 不写时按 `ui.background` 的亮度自动判断；背景色不是十六进制时按深色处理。
- 删掉主题文件后，`config.json` 里的取值会保留并回退成深色渲染，把文件放回来即恢复；启动时会提示一次。
- 预览面板固定浅色（纸张感），不随编辑器主题变化。

### 5.2 自定义语言（关键字级高亮）

内置 17 种语言之外，可以在 `languages/` 目录放 JSON 新增一种"关键字级"高亮：

1. 设置 → 编辑器与布局 → 点「打开语言目录」。首次会生成 `languages/example-toml.json`（给 `.toml` 用）。
2. 复制成新文件，文件名即语言名（只允许字母、数字、`-` `_` `.`）。
3. 回到设置页点「重新读取语言」。**新打开的文件自动生效**；已经打开的标签请在状态栏「语言」里重选一次。

```json
{
  "extensions": [".toml"],
  "aliases": ["toml"],
  "lineComment": "#",
  "blockComment": ["/*", "*/"],
  "keywords": ["true", "false"],
  "types": ["string", "integer", "float"],
  "quotes": "\"'",
  "numbers": true,
  "brackets": "[]{}()",
  "caseInsensitive": false
}
```

| 键 | 必填 | 说明 |
| --- | --- | --- |
| `extensions` | **是** | 自动识别的扩展名数组（含点，不区分大小写）；没有扩展名就没有自动生效的时机 |
| `aliases` | 否 | Markdown 围栏代码块与手动选择用的别名 |
| `lineComment` | 否 | 行注释符号（最长 4 字符）。**有它才有「切换注释」`Ctrl+/`** |
| `blockComment` | 否 | 块注释起止两串，支持跨行；不参与 `Ctrl+/` |
| `keywords` | 否 | 关键字，用 keyword 配色 |
| `types` | 否 | 类型 / 内置名，用 typeName 配色 |
| `quotes` | 否 | 字符串引号字符集合，默认 `"'` |
| `numbers` | 否 | 是否识别数字，默认 `true` |
| `brackets` | 否 | 括号字符集合，默认 `()[]{}` |
| `caseInsensitive` | 否 | 关键字是否忽略大小写，默认 `false` |

边界与规则：

- **只做关键字级高亮**：注释、字符串、数字、关键字/类型/标识符四类。没有语法树，因此**没有补全、没有诊断、没有折叠**——要这些就得上 LSP，而那不在本项目范围内。
- 与内置语言同名（例如建 `python.json`）或扩展名已被另一个自定义语言占用时，该文件会被**忽略并提示**，不会顶掉内置高亮。
- 写错键名会被跳过并提示「忽略了不认识的键 xxx」；`extensions` 写错格式会直接报错。
- `config.json` 的 `languageExtensions` 优先级仍最高，可以用它把某个扩展名指向内置或自定义语言。

### 5.3 附加语言（勾选即用）

内置 17 种之外，还有 13 种 CodeMirror 官方流模式，**默认关闭**，在 设置 → 编辑器与布局 →「附加语言」里按需勾选：

| 语言 | 自动识别 | 语言 | 自动识别 |
| --- | --- | --- | --- |
| Shell（bash / zsh） | `.sh` `.bash` `.zsh` `.ksh`，`.bashrc` 等 | Perl | `.pl` `.pm` `.t` |
| PowerShell | `.ps1` `.psm1` `.psd1` | Lua | `.lua` |
| TOML | `.toml` | Ruby | `.rb` `.rake` `.gemspec`，`Gemfile` |
| Diff / 补丁 | `.diff` `.patch` | Haskell | `.hs` `.lhs` |
| Dockerfile | `Dockerfile` `Dockerfile.dev` `Containerfile` | C# | `.cs` |
| CMake | `.cmake`，`CMakeLists.txt` | Kotlin | `.kt` `.kts` |
| HTTP 请求 | `.http` `.rest` | | |

规则：

- 勾选后才**注册**，打开对应扩展名的文件时才**加载**该模式的分片——没勾选就永远不加载、不占内存。
- 设置项存在 `config.json` 的 `legacyLanguages` 数组里（值为上表的模式名，如 `["shell","toml"]`），手写同样有效。
- 优先级：`languageExtensions` > 自定义语言 > 附加语言 > 内置映射。所以**附加语言不会顶掉**你已有的映射；扩展名被占时它会跳过并在控制台提示。
- 已打开的标签不会自动换语言，需在状态栏「语言」里重选一次。
- 这些同样是流模式而不是语法树：有正确的关键字与注释分类，但**没有补全与诊断**。

## 6 数据存在哪

全部在应用配置目录（「设置 → 关于」里可点击复制路径）：

| 文件 / 目录 | 内容 |
| --- | --- |
| `config.json` | 主题、快捷键、布局、编辑器开关等全部设置 |
| `themes/` | 自定义编辑器主题（`<名字>.json`，见 §5.1） |
| `languages/` | 自定义关键字级语言（`<名字>.json`，见 §5.2） |
| `workspace.json` | 工作区根目录、文件树展开状态 |
| `session.json` | 打开的文件、光标位置、激活标签、分栏比例 |
| `drafts/` | 未保存内容的草稿（防抖写入，按保留天数清理） |
| `replace-history/` | 批量替换的原文快照（撤销用） |
| `discard-backup/` | 放弃 Git 更改前的文件快照（保留最近 10 次） |
| `startup.json` | 最近一次的启动耗时采样（见 FAQ） |

**迁移到新机器**：把整个配置目录拷过去即可（`drafts/` 可以不拷）。

## 7 出问题时按这个顺序找

1. **状态栏的 `⚠ N`**：打开通知中心，里面是「待处理」失败与提示，带「查看详情」按钮
2. **点状态栏的消息文字**：打开「最近消息」，最近 20 条提示都在（含已经消失的）
3. **视图菜单 → 最近消息…**：同样的入口，消息已经消失时用这个
4. **`startup.json`**：只有启动耗时，用于判断「变慢」是不是真的
5. **重置配置**：关闭应用，把 `config.json` 改名备份，重启会生成默认配置

> 本应用**没有**文件日志系统。失败信息通过通知中心与错误弹窗呈现（弹窗内容可复制）。如果你需要长期留档，请自行复制保存。
