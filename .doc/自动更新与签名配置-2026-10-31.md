# 自动更新与签名配置（2026-10-31）

> 当前状态：**代码骨架已完成**（updater 插件 + 「设置 ▸ 检查更新…」+ 失败提示）。
> `tauri.conf.json` 里的 endpoint 是占位地址、`pubkey` 为空，因此现在点「检查更新」会友好失败。
> 正式发布前需要按本文补齐密钥、endpoint、签名证书与更新产物。

## 1. 生成更新签名密钥

Tauri 2 使用 minisign 兼容的密钥对：

```powershell
# 在仓库根目录执行；-w 指定私钥输出路径（不要提交到 git）
npm run tauri signer generate -w $env:USERPROFILE\.tauri\my-editor.key
```

会得到：

- 私钥：`~/.tauri/my-editor.key`
- 公钥：`~/.tauri/my-editor.key.pub`（内容是一行 base64）

## 2. 配置公钥与更新地址

编辑 `src-tauri/tauri.conf.json`：

```json
"plugins": {
  "updater": {
    "endpoints": [
      "https://your-domain.com/updates/{{target}}/{{arch}}/{{current_version}}"
    ],
    "pubkey": "<把 my-editor.key.pub 的内容整行粘进来>"
  }
}
```

- `{{target}}` / `{{arch}}` / `{{current_version}}` 由 Tauri 自动替换；
- endpoint 必须返回下面的 JSON（`platforms` 的键名按 Tauri 约定：`windows-x86_64`、`darwin-aarch64` 等）。

```json
{
  "version": "0.8.0",
  "notes": "本次更新内容",
  "pub_date": "2026-11-01T12:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "<.sig 文件内容>",
      "url": "https://your-domain.com/updates/my-editor_0.8.0_x64-setup.exe"
    }
  }
}
```

## 3. 构建时提供私钥

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY = Get-Content $env:USERPROFILE\.tauri\my-editor.key -Raw
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "<生成密钥时设置的密码>"
npm run tauri build
```

同时把 `src-tauri/tauri.conf.json` 的 `bundle.createUpdaterArtifacts` 设为 `true`（当前未开启，
避免未配置密钥时构建失败）：

```json
"bundle": {
  "createUpdaterArtifacts": true
}
```

构建产物会多出 `.sig` 文件；把安装包与 `.sig` 上传到 endpoint 对应目录。

## 4. Windows 代码签名（可选但强烈建议）

在 `tauri.conf.json > bundle > windows` 中配置证书（或使用 CI 的签名服务）：

```json
"windows": {
  "certificateThumbprint": "<证书指纹>",
  "digestAlgorithm": "sha256",
  "timestampUrl": "http://timestamp.digicert.com"
}
```

没有签名时，用户首次安装会被 SmartScreen 拦截；有签名仍建议先小范围分发。

## 5. macOS 公证（如发布 macOS）

- `bundle.macOS.signingIdentity` 改为开发者证书；
- 使用 `notarytool` 公证并装订（staple）；
- 当前配置是 `signingIdentity: null`，属于未签名状态。

## 6. 验证清单

1. 用旧版本安装包安装，配置好 endpoint/pubkey。
2. 发布一个新版本 + 更新 JSON + `.sig`。
3. 应用「设置 ▸ 检查更新…」→ 应显示版本与说明。
4. 确认下载进度、安装完成提示；重启后版本更新。
5. 断网 / endpoint 错误：应弹出「检查更新失败」，并可「打开日志目录」定位。

## 7. 安全约束

- 私钥和密码只放 CI Secret / 本机环境变量，**不要提交**；
- endpoint 必须 HTTPS；
- 更新包必须签名，客户端会校验 `pubkey`；
- 不建议在未签名状态下对外分发「自动更新」。
