# UI 美化与样式梳理（2026-11-01）

## 目标

在不改变功能与信息层级的前提下，让界面更现代、更有层次，同时把散落在 `main.css` 里的重复规则、硬编码颜色和两套动效收敛成一套可维护的体系，并把单文件 CSS 按域拆分。

## 设计令牌（`src/styles/tokens.css`）

三套主题（dark / light / high-contrast）共用同一组语义变量，组件只引用变量，不再散写颜色：

| 类别 | 变量 |
| --- | --- |
| 表面 | `--bg-app` `--bg-panel` `--bg-elevated` `--bg-input` |
| 交互底色 | `--bg-hover`（悬停浮层）`--bg-selected`（选中，带强调色倾向） |
| 边框 | `--border` `--border-subtle`（面板内部分隔）`--border-strong` |
| 文字 | `--text-primary` `--text-secondary` `--text-muted` |
| 强调 / 语义 | `--accent` `--accent-soft` `--accent-line` `--success(-soft)` `--danger(-soft)` `--warning(-soft)` |
| 差异 / JSON | `--diff-add(-soft)` `--diff-del(-soft)` `--diff-ghost` `--json-*` |
| 浮层 / 阴影 | `--overlay` `--shadow-sm/md/lg/inset`（高对比度下统一为 `none`） |
| 圆角 | `--radius-xs/sm/md/lg/xl/pill` |
| 动效 | `--dur-fast/base/slow` `--ease-out/in-out/spring` |
| 滚动条 | `--scroll-thumb(-hover/-active)` |

调整主题只需改这一处；新增组件优先复用变量。

## CSS 文件拆分（2026-11-01 追加）

拆分前 `src/styles/main.css` 为 6634 行 / 141 KB，是仓库内最大的源文件；它把主题、布局、预览排版、Git、设置和动效全部塞在一起，定位规则需要长距离滚动。

拆分方式：**按域切块，保持原文件的规则顺序**，`main.css` 只保留 `@import` 入口。

| 模块 | 行数 | 内容 |
| --- | ---: | --- |
| `tokens.css` | 272 | 设计令牌与 dark / light / high-contrast 主题 |
| `base.css` | 48 | 重置、选区、焦点环 |
| `chrome.css` | 250 | 标题栏、菜单栏、搜索框、编辑区列 |
| `preview.css` | 556 | 预览面板、Minimap、Markdown 排版、图片查看器、查找条 |
| `controls.css` | 165 | 缩放热区、品牌字标、通用按钮 |
| `shell.css` | 408 | 主区域、侧栏、滚动条、文件树、分区、打开文件 |
| `git.css` | 1075 | 源代码管理、Git 历史 / 分支 / Blame |
| `views.css` | 889 | 搜索视图、大纲、文件树行、右键菜单、标签、面包屑、命令面板 |
| `panels.css` | 688 | 运行输出、终端、搜索结果、对话框、正则 / 表格 / 最近打开 |
| `status.css` | 885 | 状态栏、通知、差异视图、大文件视图、编辑器查找面板 |
| `dialogs.css` | 692 | 设置中心、格式转换、网页抓取、代码折叠、标签新建 |
| `welcome.css` | 205 | 欢迎页、标签拖拽、拖放打开提示 |
| `editor-extras.css` | 405 | Blame 注释、预览目录 / Mermaid / KaTeX、结构化只读视图 |
| `motion.css` | 236 | 动效体系、列表过渡、reduced-motion |
| `main.css` | 20 | 仅 `@import` 入口 |

注意事项：

- `@import` 顺序就是原规则顺序，**不要随意调整**，否则同特异性选择器的覆盖关系会变。
- 拆分只改变源码组织：Vite 构建会把 `@import` 合并进同一个 CSS 产物（当前产物约 92 KB / gzip 15.6 KB），运行时请求数与体积不变。
- 每个模块顶部有「模块：xxx」头注释，新增规则放入对应域，不要再往入口文件写具体样式。

## 视觉变化

### 标题栏 / 菜单

- 品牌字标改为「主文字色 → 强调色」渐变，`flex: none + nowrap` 修掉了窄窗口下 `my-editor` 被挤成两行的问题；高对比度回退纯白。
- 搜索框改为胶囊形凹陷面，悬停提亮描边。
- 运行按钮改为胶囊形；禁用态改用中性色，运行中保持警示色（含悬停）。
- 菜单下拉：圆角 8px、留白 6px、分层阴影；条目改为圆角、淡强调底悬停，不再整条反白。
- 菜单打开态与悬停态分离（打开态淡强调底 + 强调文字）。

### 侧栏

- 分区标题行底色与面板统一，靠层级和分隔线区分；展开态改为 `--bg-selected` 淡强调底 + 2px 左侧竖条。
- 折叠箭头固定为 `›`，展开时用 CSS `rotate(90deg)` 过渡；`sidebar.ts` / `gitView.ts` 只负责写字符，方向由 CSS 表达。
- 文件树 / 打开文件 / 大纲 / 书签 / Git 的选中态统一为 `--bg-selected`，与悬停浮层明确区分。

### 标签栏 / 面包屑

- 标签改为圆角顶部、未激活透明、激活态浮起 + 顶部强调线（`box-shadow` 不额外占高度）。
- 关闭按钮固定 18×18 圆形响应区，悬停才显形。
- 标签栏、面包屑、状态栏统一使用 `--border-subtle`，减少整屏硬 1px 线。

### 欢迎页

- 顶部增加淡强调色径向光晕；标题改为渐变大字（高对比度回退纯白）。
- 动作卡片：键帽式快捷键、悬停上浮 2px + 分层阴影、按下回落。
- 标题 → 副标题 → 动作区 → 提示 → 链接错峰进场。
- 小窗口下允许滚动，不再裁掉顶部内容。

### 弹窗 / 设置 / 命令面板

- 遮罩统一 `--overlay` + 背景模糊（高对比度关闭模糊），对话框圆角 12px、分层阴影、标题字重加强。
- 设置导航选中态改为淡强调底 + 左侧竖条；设置分组改为卡片（边框 + 圆角 + 面板底色），长表单更易扫读。
- 命令面板列表项圆角 + 淡强调选中 + 左侧竖条，快捷键与命中字符在选中态下跟随强调色。
- 右键菜单、通知面板、面包屑下拉统一圆角与悬停观感。

### 状态栏 / 面板

- 状态栏改用细分隔线；Git 分支、同步、开关项增加圆角悬停反馈。
- 开关类字段（空白 / 换行等）选中态改为淡强调底 + 强调描边。
- 状态栏新增**消息历史常驻入口**（时钟图标）：瞬时消息 3 秒后消失，只要 `messageLog` 还有记录，图标就保留「最近消息」的打开路径；点击与 `⚠` 共用通知面板。
- 运行输出、终端、搜索、Git 历史面板的头部统一 28px + 细分隔线；底部面板出现时从下方滑入。

## 样式代码梳理

| 问题 | 处理 |
| --- | --- |
| 两套浮层动画（`overlay-*` 与 `ui-*`）作用于同一批选择器，后者覆盖前者 | 合并为文件末尾「动效体系」一节，统一 keyframes 与时长变量 |
| `--dur-*` 在文件末尾重复定义 | 收进 `:root` 设计令牌区，组件不再写死毫秒数 |
| `.editor-area` 定义两次 | 删除后出现的重复块 |
| `.tab` 的用户选择属性单独一条 | 合并进主规则 |
| `--bg-input` 被引用但未定义 | 三套主题补齐该变量 |
| `--text` 未定义（设置动作按钮） | 改为 `--text-primary` |
| 多处 `rgba(255,255,255,…)` 深色专用悬停底 | 改为 `--bg-hover` / `--bg-selected` / `--scroll-thumb` |
| Git 状态、差异视图、JSON 树硬编码配色 | 改为 `--warning` / `--diff-*` / `--json-*`，浅色主题不再错用深色值 |
| 各列表行重复写 hover transition | 汇总为一组「列表行 hover」过渡规则 |
| `button:hover:not(:disabled)` 特异性过高，压过组件自身悬停色 | 降为 `button:hover`，运行按钮等保留更高特异性覆盖 |

## 动效与无障碍

- 进场：遮罩淡入、面板轻弹、菜单从锚点展开、标签上浮、底部面板滑入、侧栏分区展开淡入。
- 退场：仅对话框保留（`ui/dialogs.ts` 的 `.motion-leave` + 延迟移除）。
- 交互反馈（2026-11-01 追加）：
  - 按钮 / 标签按下时下沉 1px，欢迎卡片按下时回落并轻微收紧（`scale(0.99)`）。
  - 列表行按下短暂显示选中底色，明确「点到了」。
  - 标签激活线、侧栏展开竖条、状态开关描边、设置导航竖条、命令面板选中条改为颜色过渡，不再硬切。
  - 打开文件的关闭按钮、书签删除、Git 行操作改为渐显，不再瞬间出现。
  - Git 分组展开时列表淡入，与折叠箭头旋转同步。
  - 欢迎页次级链接的下划线由透明过渡到当前文字色。
- 全部动画只涉及 `opacity` / `transform` / `box-shadow`，不参与布局，不影响输入法候选框定位。
- `prefers-reduced-motion: reduce` 下所有动画时长压到 0.01ms、迭代 1 次，过渡同时关闭。

## 比较面板加载失败的处理（2026-11-01 追加）

- `DiffService.ensurePanel` 的动态 `import()` 失败后会清空缓存的 Promise：开发服务器重启、网络抖动恢复后，下一次比较可直接重试，不会被一个已拒绝的 Promise 永久卡住。
- 「比较失败」的英文原文（`Failed to fetch dynamically imported module`）改为可操作的提示：「面板模块加载失败，请稍后重试或刷新界面」。
- 该提示仍会进入状态栏消息历史，可用新增的时钟图标回看。

## 保持不变的部分

- Markdown 预览始终是浅色文档（与编辑器主题解耦），其排版色板未改动。
- 编辑器语法主题仍由 `editor/theme.ts` 与用户主题文件控制，本次只改应用外壳。
- 侧栏行高 22px、图标 14px、缩进 12px、分区标题 24px 等既有对齐基准保持不变。
