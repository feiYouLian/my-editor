# 左侧文件树样式统一（2026-10-31）

## 排查到的问题

| # | 位置 | 问题 |
| --- | --- | --- |
| 1 | `.tree-flat-dir` | 字号 `10.5px`——半像素字号在 Windows 上会被缩放得发虚 |
| 2 | `.tree-filter-input` | `11px`，与树内正文 12px 不一致；背景 fallback 到 `transparent`，输入框和列表糊成一片 |
| 3 | `.tree-row:hover` / `.tree-row.selected` | 同为 `--bg-elevated`，鼠标划过时看不出哪一行才是选中的 |
| 4 | `.tree-flat-row`（过滤结果） | 没有左内边距，图标贴在侧栏边缘，与树内行（起点 6px）对不齐 |
| 5 | `.tree-svg` | 按文件类别上彩色（蓝/琥珀/紫/红），一屏几十行时颜色互相打架，层级反而看不出来 |
| 6 | `.tree-row[data-git-status] .tree-label` | 加 `font-weight: 500`，混排时整列文字忽粗忽细 |
| 7 | `.tree-icon` | 宽 18px，与 `gap: 4px` 组合后图标与文字间距偏挤 |
| 8 | `.open-editor`（同侧栏的「打开的文件」） | 行高 24px、图标 13px，与文件树 22px / 14px 不一致；hover 与 active 也同色 |
| 9 | `.sv-empty` / `.tree-empty` | 空态 11px vs 12px 不统一 |

## 统一后的基准

```
正文 12px · 行高 22px · 图标 14px（容器 16px） · 每级缩进 12px（起点 8px）
悬停 = --bg-hover（淡色浮层）  选中 = --bg-elevated + inset 2px accent 竖条
```

## 改动

**CSS（`src/styles/main.css`）**

- 三个主题新增 `--bg-hover`（dark `rgba(255,255,255,.06)` / light `rgba(15,23,42,.06)` / hc `rgba(255,255,255,.16)`）
- `.file-tree` 明确 `color: var(--text-primary)`、`padding: 4px 0`
- `.tree-row`：`gap: 6px`、hover 改用 `--bg-hover`
- `.tree-icon`：宽 18 → 16px
- `.tree-svg`：改为单色 `--text-secondary` + `opacity .9`，悬停 / 选中跟随文字提亮；删除 `cat-*` 彩色规则
- `.tree-flat-row`：补 `padding-left: 8px`
- `.tree-flat-dir`：`10.5px → 11px`、`opacity .8`
- `.tree-filter-input`：`12px`、`padding 4px 8px`、`border-radius 4px`、背景改 `--bg-app`
- `.tree-empty` / `.tree-error` / `.sv-empty`：统一 12px，padding 统一
- Git 状态：去掉 `font-weight: 500`，只保留颜色
- `.open-editor`：行高 24 → 22px、图标 13 → 14px、hover 与 active 分离（active 加左侧竖条）

**JS（`src/panels/fileTree.ts`）**

- 缩进由 `depth * 14 + 6` 改为 `depth * 12 + 8`，与扁平结果的 8px 起点对齐

## 展开 / 收起的间距治理（同日追加）

「展开和收缩有好多间距」的来源，逐个量出来的：

| 来源 | 原值 | 现值 |
| --- | --- | --- |
| 分区之间的 sash | 4px × 4 根 = 16px | 2px × 4 = 8px |
| 分区标题行 | 26px × 5 = 130px | 24px × 5 = 120px |
| 展开标题额外底线 | `border-bottom: 1px`，与 sash 的 1px 线相邻重复 | 删除 |
| 文件树过滤框上下内边距 | 6px | 4px |

- sash 视觉高度减半，但 `::before` 命中区从 ±4px 扩到 ±6px（2px 的线直接用鼠标抓不到），
  `sidebar.ts` 的 `SASH_H` 同步 `4 → 2`（几何计算与 CSS 必须一致，否则高度分配会多算）
- `--section-head-h` `26 → 24px`，`sidebar.ts` 的 `HEAD_H_FALLBACK` 同步
- 标题下的重复底线删除；`chevron` 固定 12px 宽度（`⌄` / `›` 字符宽度不同，原来展开/收起时标题会左右抖）
- 源代码管理的 `.git-chevron` 拉到同一尺寸
- 分区标题 hover 改用 `--bg-hover`，与「展开中」的实底区分

净效果：5 个分区全部收起时，侧栏顶部从 146px 降到 128px，且少一条重复横线。
