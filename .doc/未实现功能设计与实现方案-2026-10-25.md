## 1. Ctrl+P 文件快速打开

### 1.1 布局

复用命令面板的视觉语言（顶部输入框 + 列表 + 底部提示），不新增浮层样式：

```
┌──────────────────────────────────────────────┐
│  跳转到文件…（输入文件名或路径片段，Esc 关闭）  │
├──────────────────────────────────────────────┤
│ src/panels/preview.ts            panels/     │  ← 文件名加粗，目录弱化
│ src/app/fileService.ts           app/        │
│ README.md                        (根目录)     │
├──────────────────────────────────────────────┤
│ ↑↓ 选择 · Enter 打开 · Esc 关闭 · 共 1284 个文件│
└──────────────────────────────────────────────┘
```

### 1.2 操作

- `Ctrl+P` 打开；再次按下关闭。
- 输入即过滤：空格分隔多个关键词按「全部命中」处理（`src pre` 命中 `src/panels/preview.ts`）。
- `↑/↓` 或 `Ctrl+P/N` 选择，`Enter` 打开，`Esc` 关闭。
- 文件不存在 / 无工作区：列表空态提示「先打开一个目录（Ctrl+Shift+O 或侧栏按钮）」。
- 打开走 `fileService.openFilePath`（含大文件分流）。

### 1.3 实现

**后端**（`src-tauri/src/commands/search.rs` 新建，与搜索同模块）：

```rust
#[derive(Serialize)]
pub struct WorkspaceFile {
    pub path: String,      // 绝对路径
    pub relative: String,  // 相对 root，展示用（统一 / 分隔）
    pub name: String,
}

#[tauri::command]
pub async fn list_workspace_files(
    root: String,
    ignore_dirs: Vec<String>,
    limit: usize,          // 前端传 5000
) -> Result<Vec<WorkspaceFile>, String>
```

- 遍历用 `ignore::WalkBuilder`：`.hidden(false)`（允许点文件，但跳过 `.git` 等由 ignore_dirs 管）、
  `git_ignore(true)`、`filter_entry` 跳过 `ignore_dirs` 中的目录名。
- 只收文件（`file_type().is_file()`），跳过符号链接；按 `relative` 排序后截断 `limit`。
- `spawn_blocking` 执行（遵守"同步命令=主线程"禁令）。
- 失败返回 `Err(String)`，前端提示并空列表。

**前端**：

- `src/core/fuzzy.ts`：从 `panels/commandPalette.ts` 抽出 `fuzzyScore(query, text)`（子序列 + 连续加分），
  两个消费者（命令面板、快速打开）。命令面板改为 import。
- `src/panels/quickOpen.ts`：

```ts
export class QuickOpen {
  constructor(deps: {
    getRoot: () => string | null;
    getIgnoreDirs: () => string[];
    onOpen: (path: string) => void;
    showMessage: (text: string) => void;
  });
  open(): void;
  close(): void;
  get isOpen(): boolean;
}
```

- 缓存：`{ root, files, at }`，TTL 30s；工作区根变化或超时后重新拉取。
  打开面板时若缓存有效立即渲染，同时后台不重复请求。
- 过滤：`score = 每个关键词对 relative 的分数之和`，全部关键词必须命中（score > 0）。
- 结果渲染最多 200 条（超出提示"仅显示前 200 条"）。

**命令**：`file.quickOpen`，`defaultKey: "Mod-P"`，`section: "文件"`，`hidden: true`（不进命令面板？——
进面板更有发现性，`title: "快速打开文件…"`，不 hidden）。

### 1.4 验收

1. 无工作区按 Ctrl+P → 空态提示，不报错。
2. 打开工作区后 Ctrl+P → 1 万文件仓库首次列表 < 500ms（缓存后 < 50ms）。
3. 输入 `svc file` → 命中 `src/app/fileService.ts`；↑↓ 选择后 Enter 打开。
4. 大文件命中后仍走只读虚拟视图分流。

### 1.5 风险

- 巨型仓库（> 5 万文件）：`limit` 截断 + 30s 缓存；后续可加"索引落盘"（本轮不做）。
- `ignore` 的 gitignore 解析在非 git 目录无副作用。

## 2. 工作区搜索

### 2.1 布局（侧栏「搜索」视图）

```
┌ 侧栏 ┬─────────────────────────────┐
│ 文件 │ 搜索                         │
│ 搜索 │ [关键词________________] [Aa][.*]│
│ 大纲 │ [包含 *.ts,*.md] [排除 dist]   │
│      │ 12 个文件 · 87 处（已截断）    │
│      │ ─ src/app/fileService.ts     │
│      │   42  const data = await ...  │
│      │   88  ...                     │
│      │ ─ src/panels/preview.ts      │
│      │   17  ...                     │
└──────┴─────────────────────────────┘
```

- 顶部两个开关：`Aa` 区分大小写、`.*` 正则（与查找面板习惯一致）。
- 结果按文件分组；文件头显示相对路径 + 命中数，点击折叠/展开该组。
- 命中行双击 → `openFileAt(path, line)`（复用已有堆栈跳转）。
- 结果为空时显示「无命中」；未输入时显示使用提示（不发请求）。
- 输入防抖 300ms；`Esc` 清空输入；`Enter` 立即搜索。

### 2.2 操作

- `Ctrl+Shift+F`：聚焦侧栏搜索视图并聚焦输入框（侧栏隐藏时先展开）。
- 搜索中显示「搜索中…」，可再次输入取消上一次（请求号令牌丢弃过期结果）。
- 结果上限 200 文件 / 2000 处，超出在头部标注「已截断，请细化关键词」。

### 2.3 实现

**后端**（`src-tauri/src/commands/search.rs`）：

```rust
#[derive(Serialize)]
pub struct SearchMatch {
    pub line: u32,
    pub col: u32,
    pub preview: String,   // 单行截断 240 字符
}

#[derive(Serialize)]
pub struct FileMatches {
    pub path: String,
    pub relative: String,
    pub matches: Vec<SearchMatch>,
    pub truncated: bool,
}

#[derive(Serialize)]
pub struct SearchReport {
    pub files: Vec<FileMatches>,
    pub total_matches: usize,
    pub truncated: bool,
    pub cancelled: bool,
}

#[tauri::command]
pub async fn search_workspace(
    root: String,
    query: String,
    case_sensitive: bool,
    regex: bool,
    ignore_dirs: Vec<String>,
    max_files: usize,     // 200
    max_matches: usize,   // 2000
) -> Result<SearchReport, String>
```

- 遍历：`ignore::WalkBuilder` + `filter_entry`（跳过 ignore_dirs / 隐藏目录）。
- 文件大小上限 2 MB；读取前 8KB 检查 NUL（二进制跳过）。
- 字面量模式用 `memchr::memmem::find` 预筛（无命中直接跳过正则/行扫描）；
  正则模式编译一次复用。
- 按行扫描并记录行号/列号；单文件命中数达到剩余配额即停止并标记 `truncated`。
- `spawn_blocking`；无流式推送（一次性返回，规模受上限约束）。

**前端**（`src/panels/searchView.ts`）：

```ts
export class SearchView {
  constructor(deps: {
    getRoot: () => string | null;
    getIgnoreDirs: () => string[];
    onOpenLocation: (path: string, line: number) => void;
    showMessage: (text: string) => void;
  });
  mount(host: HTMLElement): void;
  focusInput(): void;
}
```

- 每次请求自增 `requestId`，返回后校验（与 large 过滤同型）。
- 渲染用 `DocumentFragment`；只渲染前 300 行，其余提示"细化关键词"。

**命令**：`search.workspace`，`defaultKey: "Mod-Shift-F"`，`section: "查找"`，`hidden: false`。

### 2.4 验收

1. 打开工作区，Ctrl+Shift+F 输入 `TODO` → 分组结果出现，点击跳转正确行。
2. 勾选 `Aa` 后 `todo` 与 `TODO` 结果不同；`.*` 下输入 `\bfoo\w+` 正常。
3. 在 `node_modules` 中的内容不出现在结果里（ignoreDirs 生效）。
4. 连续快速修改关键词 → 只显示最后一次的结果（无闪烁串台）。
5. 2 万文件仓库搜索 2000 处上限内 < 2s（SSD）。

### 2.5 风险

- 大仓库全量扫描会吃 CPU：上限 + 防抖 + 一次性返回；后续可加"取消令牌"。
- 正则用户输入可能导致灾难回溯：`regex` crate 默认线性时间，无回溯风险。

### 2.6 为什么本轮不做批量替换

批量替换要同时满足：预览每处改动、按文件确认、失败回滚、`.bak` 备份、编码/换行保持。
这是与"保存链路"同级的写盘风险，必须独立设计验收（参考 `batch.rs` 的既有约束：
拒绝输出路径等于源、已存在目标拒绝覆盖）。
本轮先交付"搜索 + 跳转"，替换走现有单文件 `Ctrl+H`；批量替换在下一批单独立项。

## 3. 侧栏多视图（文件 / 搜索 / 大纲）

### 3.1 布局

```
┌ 侧栏 ┬──────────────────────────────┐
│ 工作区名            [＋][☰]          │
│ ┌────────┬────────┬────────┐        │
│ │ 文件   │ 搜索   │ 大纲   │        │  ← 三等分 tab
│ └────────┴────────┴────────┘        │
│ 内容区（按 tab 切换，互不销毁）        │
└─────────────────────────────────────┘
```

- tab 固定在侧栏标题下，宽度均分；当前 tab 用底色 + 文字高亮。
- 三个视图容器常驻 DOM，切换只改 `display`（搜索输入与结果不丢失）。
- 侧栏隐藏/展开不改变当前 tab。

### 3.2 操作

- 点击 tab 切换；`Ctrl+Shift+F` 自动切到「搜索」并聚焦输入框。
- 打开文件时若当前是「大纲」，自动刷新大纲（防抖 200ms）。
- 无工作区时「文件」显示原空态；「搜索」提示先打开目录；「大纲」提示先打开文件。

### 3.3 实现

- `index.html`：`<div class="sidebar-views"><button data-view="files">文件</button>…</div>`
  + 三个容器（`#sidebar-files` 保留现有 `#file-tree`、`#sidebar-search`、`#sidebar-outline`）。
- `src/ui/sidebar.ts`：`SidebarViews` 类，管理 tab 切换 + 持久化
  （`config.layout.sidebarView: "files" | "search" | "outline"`，Rust/前端双端加字段，默认 `files`）。
- `src/panels/outlineView.ts`：

```ts
export class OutlineView {
  constructor(host: HTMLElement, deps: {
    getView: () => EditorView;
    onOpenLocation: (line: number) => void;
  });
  /** 文档/语言变化后防抖刷新 */
  scheduleRefresh(): void;
}
```

  提取规则（v1，够用且不引依赖）：
  - Markdown：正则 `^(#{1,6})\s+(.+)$`，层级按 `#` 数量缩进。
  - 其他语言：`syntaxTree(state)` 遍历，命中节点名
    `FunctionDeclaration | MethodDeclaration | ClassDeclaration | InterfaceDeclaration |
     TypeAliasDeclaration | EnumDeclaration | ObjectDeclaration | PropertyDeclaration`（CM6 Lezer 命名），
    取 `node.name` 与首行文本作为标题。
  - 节点超过 500 个截断并提示。
- 大纲点击：`view.dispatch({ selection: { anchor: pos }, effects: scrollIntoView(pos) })`。

### 3.4 验收

1. 三个 tab 切换，搜索输入与结果不丢失；重启后回到上次 tab。
2. Markdown 文档大纲按标题层级缩进，点击跳到对应行。
3. TS/Java/Python 文件大纲列出类/函数，点击跳转准确。
4. 编辑文档 200ms 后大纲刷新，不卡输入。

## 4. 拖放打开文件

### 4.1 布局

- 拖入窗口时编辑区出现虚线高亮 + 居中提示「松开以打开 N 个文件」。
- 松开后高亮消失；打开失败走状态栏消息，不弹模态。

### 4.2 操作

- 拖入文件（1..n）→ 依次打开，最后一个为激活标签。
- 拖入目录 → 弹确认「设为工作区？」（确认后 `fileTree.setRoot(dir)`）。
- 混合拖入 → 先处理目录（若多个目录只取第一个并提示），再打开文件。
- 拖入到搜索框/输入框内不拦截（仅 `event.payload.paths` 非空时处理）。

### 4.3 实现

- `src/app/dropHost.ts`：

```ts
import { getCurrentWebview } from "@tauri-apps/api/webview";

export class DropHost {
  constructor(deps: {
    onPaths: (paths: string[]) => Promise<void>;
    onHover: (active: boolean) => void;
    showMessage: (text: string) => void;
  });
  async mount(): Promise<void>;  // 注册 onDragDropEvent，返回取消函数
  dispose(): void;
}
```

- 事件：`getCurrentWebview().onDragDropEvent(ev => ...)`；`type` 为
  `enter|over` → `onHover(true)`，`leave|drop` → `onHover(false)`，`drop` 取 `ev.payload.paths`。
- 路径处理（main.ts 注入）：`await invoke("register_paths", { paths })` →
  对文件 `fileService.openFilePath`；对目录 `confirmAction` 后 `fileTree.setRoot(dir)`。
- 判定目录：`invoke("probe_file")` 只返回 size/extension，不含 is_dir。
  改为在 `drop` 时对每个路径调用 `invoke("list_dir", { path })` 判断：
  成功=目录（不展示内容，仅判定）；失败=文件。或用 `reveal_in_file_manager`？不。
  **决策**：新增轻量命令 `path_kind(path) -> "file" | "dir"`（`std::fs::metadata`），
  避免用 list_dir 探测大目录。
- CSS：`#app.drag-active .editor-area::after { content: "松开以打开"; ... }`（pointer-events:none）。
- 窗口已启用默认 dragDrop（tauri.conf.json 未关闭），`core:default` 含事件权限。

### 4.4 验收

1. 从资源管理器拖 1 个 .md 到窗口 → 打开并可编辑保存。
2. 拖 3 个文件 → 全部打开，最后一个是激活标签。
3. 拖目录 → 询问后设为工作区，文件树刷新。
4. 拖入期间高亮出现，松开/离开后消失。

## 5. 标签拖拽排序

### 5.1 布局

- 拖动中的标签半透明（`opacity: .6`）。
- 目标位置显示 2px 竖线指示（`::before` 或独立 div），不改变标签宽度。

### 5.2 操作

- 按住标签移动超过 4px 才进入拖拽（避免与点击切换冲突）。
- 拖到某标签左/右半边 → 插入到该位置前/后；拖出标签栏范围 → 取消。
- `Esc` 取消拖拽；松开后 `tabStore.move(id, index)` 并持久化会话。
- 不触发 `onActivate`（拖拽结束不切换激活标签）。

### 5.3 实现

- `ui/tabsBar.ts`：`pointerdown` 记录起点与 tabId；`pointermove` 超过阈值后
  `setPointerCapture`，用 `document.elementFromPoint` 找目标标签并计算插入索引；
  `pointerup` 提交；`pointercancel` 清理。
- `store/tabs.ts` 新增：

```ts
/** 移动标签到指定索引（clamp 到合法范围）；返回是否发生变化 */
move(id: string, toIndex: number): void;
```

  内部：从 `tabs` 数组 splice 出该 tab，插入到 `toIndex`，`emit("structure")`。
  会话持久化由既有 `tabStore.subscribe` 的 `structureChanged()` 覆盖（顺序进入 session.json）。

### 5.4 验收

1. 拖第 1 个标签到第 3 个位置 → 顺序变化，激活标签不变。
2. 重启后顺序保持（session.json 记录顺序）。
3. 单击标签仍正常切换（未误触发拖拽）。

## 6. formatOnSave 接入

### 6.1 操作

- 设置 ▸ 页面布局 ▸ 编辑器新增开关「保存时自动格式化」（`formatOnSave`，默认关）。
- 保存（Ctrl+S / 全部保存）时：支持格式化的语言先格式化再落盘。
- 格式化失败（工具缺失/语法错误）：状态栏提示首行，**仍然保存原内容**（不阻塞、不丢字）。
- 大文档（> 10000 行）跳过自动格式化并在状态栏说明（避免保存卡顿）。

### 6.2 实现

- `app/fileService.ts` 的 `writeTo` 增加可选的"保存前格式化"钩子：

```ts
export interface FileServiceDeps {
  // ...
  /** 保存前格式化（仅激活标签；返回是否已应用） */
  formatBeforeSave?: (tab: Tab) => Promise<"applied" | "skipped" | "failed">;
}
```

- `saveFile` / `saveFileAs` / `saveAllFiles` 写盘前：
  - `getConfig().formatOnSave` 且 `tab.id === editorHandle.docId()` → 调用钩子；
  - `failed` 只提示，继续保存；`skipped` 静默。
- 钩子在 main.ts 实现：复用 `formatDocument(view, effectiveLanguage(tab), tab.path)`，
  但避免其状态栏 "格式化完成" 噪音——增加 `silent` 参数（`formatDocument(..., { silent: true })`）。
- 注意：格式化会修改编辑器内容（未保存基线），随后 `writeTo` 快照写盘，落盘内容与编辑器一致；
  `markSaved(id, written, meta)` 语义不变。

### 6.3 验收

1. 开启开关，修改 JSON 后 Ctrl+S → 落盘内容已格式化，脏标记清除。
2. 未安装 black 的 Python 文件保存 → 提示安装指引，文件仍保存成功。
3. 关闭开关 → 保存不改内容。

## 7. 设置中心「文件与会话」页

### 7.1 布局

```
┌ 设置 ──────────────────────────────┐
│ 外观 │ 编辑器 │ 文件与会话 │ 快捷键  │
├────────────────────────────────────┤
```

```ts
  open(rows: DraftRow[]): Promise<string[] | null>;
```

  1. `listDrafts()` → 过滤出属于当前工作区的草稿（沿用现有过滤规则）；

  4. `全部忽略` → `deleteDraft` 批量。

### 8.4 验收
