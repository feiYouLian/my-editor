## K. 附录：测试数据生成（PowerShell）

```powershell
$root = Join-Path $env:TEMP "my-editor-acceptance"
New-Item -ItemType Directory -Force $root | Out-Null
$text = "这是一段较长的中文测试文本，用于确认编码检测的稳定性。foo 结尾。`r`n第二行：中文测试`r`n"

# GBK / Big5 / UTF-16LE / UTF-8
[IO.File]::WriteAllText((Join-Path $root "gbk.txt"), $text, [Text.Encoding]::GetEncoding(936))
[IO.File]::WriteAllText((Join-Path $root "big5.txt"), "這是一段較長的中文測試文本。", [Text.Encoding]::GetEncoding(950))
[IO.File]::WriteAllText((Join-Path $root "utf16le.txt"), $text, [Text.Encoding]::Unicode)
Set-Content -Path (Join-Path $root "utf8.txt") -Value $text -Encoding utf8

# Windows-1252
[IO.File]::WriteAllText((Join-Path $root "cp1252.txt"), "café naïve", [Text.Encoding]::GetEncoding(1252))

# >20MB GBK 日志（用于虚拟视图/编码切换/跟随）
$log = Join-Path $root "big-gbk.log"
$line = "2026-10-31 12:00:00 INFO 中文日志行 foo bar baz`r`n"
$sw = [IO.StreamWriter]::new($log, $false, [Text.Encoding]::GetEncoding(936))
while ($sw.BaseStream.Length -lt 21MB) { $sw.Write($line) }
$sw.Close()

# 250 个文件（快速打开 >200）
$many = Join-Path $root "many"
New-Item -ItemType Directory -Force $many | Out-Null
1..250 | ForEach-Object { Set-Content -Path (Join-Path $many ("file-{0:D3}.txt" -f $_)) -Value "item $_" -Encoding utf8 }

# 工作区外单文件（插图测试）
$single = Join-Path $root "single"
New-Item -ItemType Directory -Force $single | Out-Null
Set-Content -Path (Join-Path $single "outside.md") -Value "# 单文件插图测试`r`n" -Encoding utf8

$root
```
